## TCP/IP mode
TCP/IP is the core set of network protocols upon which the modern Internet is built.
It is similar to the OSI model but has only 4 layers instead of 7.

### Layers
L1 - Network Access
Combines L1 and L2 of the OSI model. 
Responsible for physical transmission of data — cables, switches, MAC addresses.
L2 - Internet
Corresponds to L3 of the OSI model. 
Handles logical addressing and routing of packets using IP addresses.
L3 - Transport
Corresponds to L4 of the OSI model. 
Ensures data transmission between two applications through ports. Uses TCP (reliable) or UDP (fast).
L4 - Application
Combines L5, L6, and L7 of the OSI model. 
Handles encoding, encryption, sessions, and user-facing protocols such as HTTP, FTP, and DNS.
